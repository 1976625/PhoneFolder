## 4. 踩坑与修复

1. **`app.getFileIcon` 在本机只返回 32×32 图标**，放到 64px 格子里放大发糊，文件夹还带内容预览的小图。
   → 文件夹、图片、视频改用 `nativeImage.createThumbnailFromPath()` 的 **256px 缩略图**；只有 `.md/.docx/.lnk` 等无缩略图的才回退 32px 图标（居中 44px 显示）。
2. **图标被裁切成局部放大**：先用 inline 的 `background` 简写画渐变占位，简写会把 `background-size` 重置为 `auto`，CSS 类里的 `cover/44px` 覆盖不过 inline。
   → 加载图标时把 `background-size / position / repeat` 也 inline 明确写回。
3. **过滤规则**：除隐藏文件、`desktop.ini`、`thumbs.db`、`$RECYCLE.BIN`、`System Volume Information` 外，补充 `.` 开头和 **`~$`（Office 临时锁定文件）**。
4. 图标 kind（`thumb` 铺满 / `icon` 居中）改由主进程随 dataURL 一起返回，渲染层不再猜扩展名。
