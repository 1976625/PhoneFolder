# PhoneFolder 开发计划（v0.2）

> 给 Windows 桌面做一个免费的“手机桌面文件夹”：桌面上常驻一格瓦片，单击后整个屏幕压暗、壁纸模糊，瓦片原地放大成毛玻璃网格；点外面收起。背后绑定真实文件夹（可绑多个，每个瓦片一个文件夹）。
>
> 交互基准：DeskFolders（Steam，付费）。定位差异：不替代资源管理器，只在桌面上加一层“文件夹入口 + 展开层”。

- 计划版本：v0.2（2026-10-27 修订，替代 v0.1）
- 项目根：**`D:\deskTop\phoneS`**（当前工作区即仓库根，不再套 `phone-folder` 子目录）
- 目标平台：Windows 11（本机 1920×1080 单屏，Win11 26H2 build 26300）
- 运行环境：Node.js v24.16.0 + pnpm 10.28.0（本机已具备，全程用 pnpm）
- 项目代号：PhoneFolder（package name `phone-folder`，productName `PhoneFolder`，appId `local.phonefolder`）

## 1. 目标与成功标准

一句话目标：**让桌面上的一个文件夹入口，点开时“感觉像手机”，而不是像 Windows 资源管理器。**

成功标准（MVP）：
1. 桌面上出现一个美观瓦片（默认放在主屏右上角、避开左侧任务栏），显示绑定文件夹的 2×2 缩略图和名字。
2. 单击瓦片 → 全屏浮层 ≤150ms 出现，背景是压暗 + 模糊的**当前桌面**（动态壁纸也正确），面板从瓦片位置放大。
3. 浮层里是真实文件夹内容，点图标能打开文件；点面板外 / Esc / 再点瓦片位置都能收起，动画反向。
4. 能把文件从资源管理器拖进瓦片（= 移入文件夹），也能把面板里的文件拖出去（单文件）。
5. 日常可用：托盘常驻、绑定/更换文件夹、多瓦片配置、重启后配置不丢。
6. `pnpm shot` 能一键产出瓦片态 / 展开态截图，作为每轮验收证据。

## 3. 技术方案（已确定，不在开发中反复）

| 项 | 选择 | 理由 |
|---|---|---|
| 运行时 | **Electron 43.3.0（锁版本）** | 本机已有该版本二进制缓存；CSS 动画与毛玻璃成本最低 |
| 渲染层 | 原生 HTML/CSS/JS，不用 React | 只有 3 个页面，省构建链、启动更快、调试直接 |
| 进程模型 | main + preload（contextBridge）+ renderer | `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`；文件操作全走 IPC 白名单 |
| 窗口 | ①瓦片窗（1..N） ②浮层窗（每显示器一个，单屏复用） ③设置窗（懒创建） | 浮层启动后空闲预创建并隐藏，保证打开 ≤150ms |
| 背景模糊 | ①Win11 DWM acrylic ②desktopCapturer 1/4 截图 + CSS blur ③静态壁纸预模糊（兜底） | 见 3.2，三级回退保证任何壁纸/任何 Win 版本都有像样的效果 |
| 图标 | `app.getFileIcon` + `nativeImage.createThumbnailFromPath` + 内存/磁盘缓存 | 主进程调用，renderer 只拿 dataURL |
| 数据 | `app.getPath('userData')/config.json` | 可读可手改，方便调试；原子写 + 损坏备份 |
| 打包 | electron-builder：portable zip 优先，NSIS 次之 | 先免安装试用；P5 才需要下载 NSIS/winCodeSign，走 npmmirror 镜像 |

### 3.1 窗口与图层

```
桌面（壁纸 + Explorer 图标，壁纸由 Wallpaper Engine 动态渲染）
  └─ 瓦片窗（84×84，无边框、透明、skipTaskbar、不在 Alt+Tab、非置顶、不抢焦点）
       └─ 单击 → 浮层窗（该显示器 bounds 全屏、置顶、skipTaskbar、无边框、隐藏后预创建）
             ├─ 背景：DWM acrylic（或截图 + CSS blur）+ 压暗 rgba(0,0,0,.45)
             └─ 面板：3×3 网格（半透明白 + 圆角 + 高光描边 + 大投影）
```

| 窗口属性 | 瓦片窗 | 浮层窗 |
|---|---|---|
| 尺寸 | 84×84 DIP（设置可 64–128） | `display.bounds`（**含左侧任务栏 48px**，手机风格铺满整屏） |
| frame / transparent | false / true | false / true，`backgroundColor:'#00000000'` |
| 背景材质 | 无（自绘缩略图 + 圆角 + 投影） | `backgroundMaterial:'acrylic'`（Win11 22H2+；失效走截图回退） |
| 层级 | 非置顶（普通桌面浮窗） | `alwaysOnTop: true`（普通 topmost，不用 screen-saver 级） |
| 任务栏 / Alt+Tab | `skipTaskbar: true`（Windows 上同时移出 Alt+Tab） | 同左 |
| 焦点 | `focusable: true`（要能拖动/点击） | `focusable: true`（需要 Esc、滚轮、滑动） |
| 其他 | `resizable:false`、`hasShadow:false`、`movable:true`（手动拖） | `resizable:false`、`movable:false`、`roundedCorners:false` |
| 渲染进程 | `backgroundThrottling: false`（隐藏时也保持可渲染，首帧不卡） | 同左 |

**打开/关闭时序（目标 ≤150ms）**
1. 瓦片 `mouseenter` 时预热：主进程抓一帧桌面缩略图（截图方案用），或确认 acrylic 可用（主方案用）。
2. 单击：主进程 `overlay.show()` + 通过 IPC 下发瓦片屏幕坐标（DIP），renderer 用该坐标做 `transform-origin` 和起始 `translate/scale`。
3. 关闭：点面板外 mousedown、Esc、或点击落在瓦片 bounds 内（overlay 坐标 = 瓦片 DIP 坐标 − display.bounds 原点）。
4. 关闭后 `overlay.hide()`，焦点交还桌面。

**DPR / 坐标系约定**：配置和 IPC 一律用 DIP；截图和 CSS 用物理像素；两者换算只在 `wallpaper` / `shot` 模块内做一次。

### 3.2 关键技术点

**① 背景模糊三级方案**

| 优先级 | 方案 | 做法 | 适用/说明 |
|---|---|---|---|
| A（首选） | DWM acrylic | `transparent:true` + `backgroundColor:'#00000000'` + `backgroundMaterial:'acrylic'`；renderer 层 `background: transparent`，再叠压暗层 | Win11 22H2+；**实时模糊**，动态壁纸、桌面图标都自动被模糊，零截图成本；需真机验证“透明 + acrylic”组合（P1 30 分钟 spike） |
| B（回退） | 截图 + CSS blur | 主进程 `desktopCapturer.getSources({types:['screen'], thumbnailSize: 480×270})` 抓当前屏 → dataURL 给 renderer → `filter: blur(20px)` 放大铺满 | acrylic 失效（Win10、关闭透明效果、截图黑屏）时用；单帧约 30–60ms，靠 hover 预热压到预算内 |
| C（兜底） | 静态壁纸 | 注册表 `WallPaper` → `TranscodedWallpaper` → 纯色渐变；1/4 分辨率预模糊 | 只有 A、B 都不可用时才用；动态壁纸场景下会“一眼假”，仅保证不崩 |

**② 拖入取路径（必坑）**：Electron ≥32 移除 `File.path`，renderer 里 `dataTransfer.files[0].path` 为 `undefined`。必须在 preload 暴露：
```js
// preload.js
const { contextBridge, webUtils } = require('electron')
contextBridge.exposeInMainWorld('phoneFolder', {
  getPathForFile: (f) => webUtils.getPathForFile(f),
  // ... 其它 IPC API
})
```
`dragover` 和 `drop` 都要 `preventDefault()`，否则不会触发 drop。

**③ 拖出**：renderer `dragstart` → IPC → main `webContents.startDrag({ file, icon })`；MVP 限单文件（R3）。

**④ 文件夹扫描规则（先写死，避免 P2 反复改）**
- `fs.promises.readdir(dir, { withFileTypes: true })`
- 过滤：以 `.` 开头、`desktop.ini`、`thumbs.db`、`$RECYCLE.BIN`、`System Volume Information`
- 排序：文件夹优先，然后 `localeCompare(b, 'zh-CN', { numeric: true })`
- `.lnk` 正常显示；符号链接/junction 只显示不递归；分页 = 每页 9 项，扫描上限先 500 项
- 打开的图标：`shell.openPath()`；删除：`shell.trashItem()`；右键：原生 `Menu.popup()`

**⑤ 图标/缩略图缓存**：key = `路径|mtime|尺寸`；内存 LRU 200 项；磁盘 `userData/icon-cache/`（P5 可清空）。图片/视频先试 `createThumbnailFromPath`，失败回退文件图标。

**⑥ 文件变化刷新**：`fs.watch(folder)` + 300ms 去抖重扫；`ENOENT`（文件夹被删）弹中文提示并进空态。

**⑦ 打开文件失败 / 跨盘移动**：移动用 `rename` 优先，`EXDEV` 时 copy + unlink；同名冲突自动加 ` (1)` 后缀；失败提示中文原因。

**⑧ 自动化截图（新增）**：`pnpm shot` 启动应用 → 依次截：瓦片态、点击展开后的整屏（用 `desktopCapturer` 抓真实合成画面，才能看到 acrylic 效果）、收起后 → 存 `shots/*.png` 后退出。开发参数：`--no-tile`（不显示瓦片）、`--open`（启动即展开浮层）、`--shot-dir`。

**⑨ 单实例 / 托盘 / 自启**：`app.requestSingleInstanceLock()`；托盘菜单（显示瓦片 / 打开设置 / 退出）；`app.setLoginItemSettings()`。

### 3.3 本机环境事实（2026-10-27 实测，供排期参考）

| 项 | 实测值 | 影响 |
|---|---|---|
| 桌面路径 | `D:\deskTop`（注册表 User Shell Folders 重定向，不是 `%USERPROFILE%\Desktop`） | 默认绑定文件夹 = `D:\deskTop`（38 项：13 文件夹 + 20 快捷方式 + 文档） |
| 屏幕 | 1920×1080，主屏；工作区 `X=48,Width=1872` → **任务栏在左侧占 48px** | 瓦片默认位置避开左侧；浮层铺满 `display.bounds` |
| 壁纸 | Wallpaper Engine 运行中（wallpaper64/wallpaperservice32），`WallPaper` 指向 `WallpaperEngineOverride_randomKSOWVA.jpg` | 静态壁纸方案不可靠，必须 acrylic 或截图（见 3.2 ①） |
| Electron | `%LOCALAPPDATA%\electron\Cache` 已有 `electron-v43.3.0-win32-x64.zip`（144,396,349 B）；npmmirror 下载实测 6.3MB/s | 锁定 43.3.0；装包最坏 ~25s 下载；必要时 `electron_skip_binary_download=true` + 用缓存 zip 手动解压到 `node_modules/electron/dist`（并写 `path.txt`）完全离线兜底 |
| npm | npm 11.13.0 本机损坏（`npm view` 报 `Class extends value undefined`） | **全程 pnpm**，不要用 npm 装包 |
| 网络 | registry.npmmirror.com 正常；electron 43.3.0 二进制 HEAD 200 | 依赖安装、P5 打包二进制都走镜像 |
| 其他 | 无 .NET SDK / 无 Rust；git 2.44 可用 | 保持 Electron，不换技术栈 |

## 4. 交互与视觉规格（验收基准）

| 元素 | 规格 |
|---|---|
| 瓦片尺寸 | 84×84 DIP（设置可 64–128），圆角 20，2×2 缩略图各 36，圆角 8 |
| 瓦片文字 | 12px 单行，底部居中，超长省略 |
| 瓦片默认位置 | 主屏右上角：x = 1920−84−24 = 1812，y = 24；之后记忆拖动位置 |
| 展开动画 | 380ms，`cubic-bezier(0.22, 1, 0.36, 1)`，scale 0.55→1，opacity 0→1，origin 在瓦片中心 |
| 收起动画 | 240ms，反向，`cubic-bezier(0.4, 0, 1, 1)` |
| 浮层背景 | acrylic（实时模糊）或截图 blur(20px)，压暗 `rgba(0,0,0,.45)`，轻微暗角 |
| 面板 | 3×3，格子 112px，间距 24，内边距 32，圆角 36；背景 `rgba(255,255,255,.10)` + 1px 高光描边 + 大投影 |
| 分页 | 每页 9 项；底部圆点；滚轮 / 左右方向键 / 横向滑动翻页 |
| 关闭方式 | Esc、点面板外、点击瓦片原位置 |
| 空文件夹 | 面板中央“把文件拖到这里”占位 + 瓦片显示空文件夹样式 |
| 拖入反馈 | 瓦片/面板高亮描边，释放后“已移入”轻提示 |
| 多瓦片 | 最多 6 个，各自绑定文件夹、各自记忆位置；同一文件夹不重复绑定 |

## 8. 性能与质量预算

| 指标 | 预算 |
|---|---|

## 9. MVP 验收清单（P5 必须全过）

1. 桌面出现瓦片，显示绑定文件夹前 4 个图标 + 文件夹名；默认在右上角、不压左侧任务栏。
2. 单击瓦片 → 浮层 ≤150ms 出现；背景是压暗 + 模糊的当前桌面（Wallpaper Engine 动态壁纸也正确）。
3. 面板显示真实内容，超过 9 项出现分页圆点，滚轮/方向键/滑动可翻页。
4. 单击文件/文件夹能打开；点面板外、Esc、点瓦片原位置都能收起，动画反向。
5. 从资源管理器把文件拖到瓦片上 → 文件被移入绑定文件夹，瓦片缩略图自动刷新。
6. 从面板把文件拖到资源管理器/桌面 → 生成系统拖放（单文件）。
7. 托盘可显示/隐藏瓦片、打开设置、退出；设置可更换绑定文件夹。
8. 重启后瓦片位置、配置、绑定文件夹不丢；开机自启开关生效。
9. 多瓦片：设置里能加第二个瓦片（不同文件夹），两个瓦片互不干扰。
10. 空文件夹、文件夹被删、无权限、磁盘满等异常有中文提示且不崩。
11. 内存、空闲 CPU 在预算内；动画无可感知掉帧；控制台无报错。
12. `pnpm shot` 产出的截图能复核上述视觉项。

## 23. v0.9.2 文件夹图标统一半透明（2026-10-27，按反馈）

详见 [v0.9-进展.md](v0.9-进展.md) §6：

1. **反馈**：浮层里有的文件夹图标是黑色方块、有的半透明。
2. **根因**：Shell 返回的文件夹缩略图格式不统一——带照片预览的部分是 RGB（无 alpha、纯黑背景），其余是 RGBA 透明。

4. **验证**：14 个文件夹四角 alpha 全 0，面板统一玻璃背景；截图 `shots/crop-folder-icons.png`；单测 13/13。
5. 版本 0.9.2，重新打包 portable + zip。
