# v0.10.0 固定 128 尺寸 + 桌面图标式网格吸附（2026-10-27）

> 计划：[计划-固定尺寸与网格吸附.md](计划-固定尺寸与网格吸附.md)（按「推荐」方案 A 实现）

## 1. 瓦片固定 128px

- 新增 `src/main/services/grid.js`：`TILE_SIZE = 128`、`LABEL_HEIGHT = 20`、`GRID_GAP = 16`、`GRID_PAD = 8`、`CELL_W = 144`、`CELL_H = 164`；
- 设置页删除「瓦片大小」滑块，瓦片尺寸固定 128（窗口 128×148）；
- `tiles[].size` 字段保留并固定写 128，旧配置（v4 及更早）读入时统一归一；
- 配置版本 **v4 → v5**：只做尺寸归一，不再做 v2/v3 那样的收纳目录迁移（v4 已完成过）。

## 2. 网格吸附

- 网格区域 = 主显示器 `workArea`（自动避开任务栏）+ 四周 8px 留白；本机（1920×1080、任务栏在左）为 **13 列 × 6 行**，x 56–1784、y 8–828；
- 拖动瓦片：自由跟随鼠标，但限制在 `workArea` 内（不会拖到任务栏下面）；
- **松手吸附**：计算最近单元格 → 若被其它瓦片占用则找最近的空格 → 约 120ms 小补间滑入 → 写回配置；
- 启动/加载配置时也会统一吸附一次（旧自由坐标自动归位）；
- 两个瓦片不会落同一格。

## 3. 设置页

- 删除尺寸滑块；
- 新增「重新对齐到网格」按钮：换分辨率/任务栏位置后一键把全部瓦片重新吸附（补间动画 + 保存）；
- 瓦片提示补充：尺寸固定 128、拖动松手吸附网格。

## 4. 验证

- 单测 **20/20**（新增 gridMetrics / nearestCell / 空格避让 / v4→v5 迁移用例）；
- 新增 `scripts/e2e-grid.js`：拖动瓦片 → 位置落在 144×164 网格、尺寸 128、两瓦片不同格 → **PASS**；
- 回归：拖出/排序/重命名/连续开合/设置页 E2E 全部 PASS；
- 本机迁移实测：配置变 v5，两个瓦片吸附到 (1784,8) 与 (1784,172)（右侧同一列相邻两行）。

## 5. 已知限制

- 网格只保证瓦片之间对齐与贴边，不读取 Windows Explorer 的图标间距（方案 B，作为后续可选）；
- 仅主显示器；多显示器场景后续再做。
