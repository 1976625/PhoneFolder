## 4. 实现要点 / 注意

1. **取路径必须用 preload 的 `webUtils.getPathForFile()`**：Electron ≥32 移除了 `File.path`，渲染层直接读 `dataTransfer.files[0].path` 是 undefined。
2. **drop 一定要 `preventDefault`**：`dragenter / dragover / dragleave / drop` 全部 `preventDefault`，否则 Chromium 不会触发 drop。
3. **拖出用「`dragstart` → preventDefault → IPC → `webContents.startDrag`」**：这是 Electron 官方 Native File Drag & Drop 的用法；拖拽图标直接用渲染层已缓存的缩略图 dataURL，避免二次取图标。
4. **拖入时点面板外不关闭浮层**：关闭只绑 `mousedown`，drop/drag 不会触发，避免拖入瞬间浮层被关掉。
5. **安全校验**：`files:drop-in` 校验 sender 必须是瓦片/浮层页；路径数量 ≤60；`item:drag-out` 校验目标路径仍在绑定文件夹内。
6. 移入完成后主动 `refreshAndBroadcast()`，同时 `fs.watch` 去抖兜底；瓦片 label 的「已移入 N 项」先用临时反馈，1.9s 后恢复。

## 5. 手动验收步骤

1. `pnpm start`，桌面上出现瓦片。
2. 从资源管理器拖 1 个文件到瓦片上 → 瓦片高亮，松手后 label 显示「已移入 1 项」，2×2 预览刷新。
3. 单击瓦片展开 → 从资源管理器拖 2 个文件到浮层任意位置 → 出现「松手移入「deskTop」」提示，松手后 toast「已移入 2 项」，列表刷新。
4. 同名文件再拖一次 → 目标文件夹里出现 `xxx (1).ext`，不覆盖原文件。
5. 把浮层里的某个文件拖到桌面 → 资源管理器出现原生拖拽，松手后文件移出（单文件）。
6. 同一文件夹内再把该文件拖回瓦片 → 提示「已在目标文件夹内」，不重复移动。

## 6. 已知限制

- 拖出一次只能一个文件（Electron 能力上限，v2 计划用 native 模块或切 .NET 补）
- 拖入默认是**移动**；Ctrl=复制 的修饰键语义未做（v2）
- 拖拽时的系统拖拽图像只有图标，没有多选/计数提示（Electron 限制）
- 跨盘大文件夹复制没有进度条，大文件会卡一下（P5 可加进度/toast 提示）
