## 4. 实现要点

1. **多瓦片**：`tileWindows: Map<tileId, BrowserWindow>`、`folderStates: Map<tileId, {data, watcher, timer}>`；
   所有 IPC 通过 sender 反查 tileId（浮层额外记录 `overlayTileId`），拖入/打开/图标校验都用该瓦片的文件夹。
2. **设置保存 = 保存 + 重建**：`sanitizeSettings` 校验（中文报错）→ 写 config → 销毁旧瓦片/浮层 → 重新扫描、建窗口、挂 watcher → 重建后预热背景缓存。重建期间 `window-all-closed` 不退出。
3. **瓦片 id 重新编号**：保存时统一 `t1..tN`，避免增删后 id 空洞；重建成本可接受（保存是低频操作）。
4. **开机自启**：`app.setLoginItemSettings({ name:'PhoneFolder', path: app.getPath('exe'), args: app.isPackaged ? [] : [app.getAppPath()] })`。
   注意开发模式下不传 `name` 会写成 `electron.app.Electron`，所以显式指定 name；取消勾选时同一 name 会移除注册表项。
5. **设置窗置顶**：DSH 等透明窗口可能盖住设置窗，打开时 `app.focus({ steal:true })` + `show/focus/moveTop`。
6. **背景方案优先级**：`PF_BG` 环境变量 > 设置里的 `overlay.background` > `wallpaper`。
7. 数值夹取在**读取 config 时也做一遍**（手改 config 不至于把界面弄坏）。

## 6. 已知限制（P4 后）

- 托盘菜单「显示/隐藏瓦片」只在本次运行内生效（不写 config）
- 拖入/拖出仍是单文件拖出、移动语义
- 多显示器未适配（设置页/瓦片坐标均按主屏）
- 设置页瓦片大小为全局调整（所有瓦片一致），暂不支持单个瓦片不同大小（config 支持，UI 未暴露）
