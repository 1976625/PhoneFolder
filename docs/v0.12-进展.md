# v0.12.0 桌面级瓦片（Progman 子窗口，实验）(2026-10-29)

> 需求：「按你说的改吧」→ 实现 C 方案：把瓦片挂到 Windows 桌面层（Progman 子窗口），实现 Win+D 不收起 + 始终在普通软件下面。
> 设计原则：**实验开关、默认关、失败自动回退普通窗口模式**。

## 1. 实现方式

- 新增 native helper 能力（`src/main/services/native-window.js`）：
  - `attach`：用 `EnumWindows` 找到 `Progman`（本机 `FindWindow('Progman')` 返回 0，必须枚举）→ 去掉 `WS_POPUP`、加 `WS_CHILD` → `SetParent(progman)` → 显式 `SetWindowPos` 设置位置/尺寸并显示；
  - `detach`：反向操作，恢复顶层窗口；
  - `position`：子窗口坐标移动（父窗口客户区坐标，物理像素）；
  - `show/hide`、`bounds`（`GetWindowRect`）、`health`（IsWindow/GetParent/可见性）；
  - 请求带 `@id` 标签，helper 回包 `@id ok ...`，主进程用 Promise 等待（2.5s 超时回退）。
- `main.js` 接入：
  - `app.tileMode === 'desktop'` 时，瓦片窗口 ready 后挂到桌面；DIP→物理坐标用 `screen.dipToScreenRect`；
  - 拖动/网格吸附在桌面模式下走 native `position`（带动画补间），不再依赖 Electron `setPosition`；
  - 浮层展开起点用 `desktopRects` 记录的屏幕坐标（避免子窗口 `getBounds` 语义差异）；
  - 托盘显隐对挂载窗口用 native `show/hide`；
  - `applyDesktopState` / `bottomAllTiles` 在桌面模式下跳过（不再需要 Win+D 检测 + 临时置顶）；
  - 每 2.5s 健康检查：父窗口丢失（Explorer 重启）/不可见 → 自动重挂；显示器变化/解锁屏也触发重挂；
  - 挂载失败自动回退普通窗口模式（保留现有 B 方案逻辑）。
- 设置页：系统区新增「桌面级瓦片（实验）」开关 + 说明；开启后 Win+D 可见开关置灰；保存走 `rebuildAll` 重建窗口并挂载。
- 配置：`app.tileMode: 'window' | 'desktop'`，默认 `window`；旧配置自动补默认值，无需迁移版本。

## 2. 关键排查记录

1. **FindWindow('Progman') 返回 0**：改用 `EnumWindows` 枚举类名找 Progman，兜底找带 `SHELLDLL_DefView` 的 WorkerW。
2. **点击/拖动无响应**：本机 PowerShell 的 `SendInput` 绝对坐标在当前桌面环境不稳定（光标位置不一致），改用 `SetCursorPos + mouse_event` 后点击可以正常打开浮层；拖动用 tile 页面 CDP 的 `dragStart/dragMove/dragEnd` 验主进程逻辑（移动 + 落格 + native 窗口跟随均通过）。
3. **拖动坐标 bug**：桌面模式下 `drag.base` 用了对象 `{x,y}` 却按数组下标取值 → NaN，拖动瞬间把坐标写坏（JSON 里变成 null）。已改为统一数组，并加 `Number.isFinite` 防护。

## 3. 验证

- 单测 **21/21**（新增 tileMode 校验/回落用例）；
- 新增 `scripts/e2e-desktop-mode.js` → **PASS**：
  - 5 个瓦片全部为 `Progman` 子窗口（WS_CHILD、可见）；
  - Win+D 后 5 个瓦片仍可见，前台为 `Progman`；
  - 点击瓦片能打开浮层；
  - 模拟拖动后配置坐标落到网格（x=94+130n、y=8+148n），窗口 native 位置同步。
- 普通窗口模式回归全绿：单测、排序/排序 DOM/边缘翻页/拖出/重命名/连续开合/网格吸附/设置页 E2E。

## 4. 已知限制

- 仅主显示器；多显示器/混合 DPI 未适配；
- Explorer 重启/锁屏/分辨率变化会自动重挂，但极端情况下可能需要重启应用；
- 若环境中 PNG 子窗口行为异常，会自动回退普通窗口（设置里可手动关闭实验开关）；
- `--shot` 截图模式强制使用普通窗口（避免与全屏 backdrop 冲突）。
