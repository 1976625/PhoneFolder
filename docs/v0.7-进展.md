# v0.7.0 收纳位置修正（2026-10-27）

> 反馈：「我电脑设置显示隐藏文件夹的时候桌面会显示隐藏的这个文件夹，有没有办法处理」
> 上一版本：[v0.6 进展](v0.6-进展.md)

## 1. 问题

v0.6 的默认收纳文件夹是 `<桌面>\手机文件夹`（靠 `attrib +h` 隐藏）。一旦在资源管理器里开启
「显示隐藏的项目」，这个文件夹就会出现在桌面上，和「桌面保持干净」的初衷冲突。
另外 `.lnk`/大文件夹从桌面拖入时，若收纳目录不在同一磁盘还会走跨盘复制。

## 2. 方案

**把收纳文件夹移出桌面目录，放到「桌面目录的同级」**：

- 本机桌面 = `D:\deskTop` → 收纳文件夹 = **`D:\手机文件夹`**
  （普通桌面在 `C:\Users\<user>\Desktop` 时会放在 `C:\Users\<user>\手机文件夹`）
- 它与桌面**同一磁盘**：从桌面拖入走 `rename`，大文件/文件夹瞬间移动，不跨盘复制；
- 它**不在桌面目录内**：无论是否开启「显示隐藏的项目」，桌面都不会再冒出收纳文件夹；
- 不再需要隐藏属性，也不用 `attrib +h`。

## 3. 迁移（配置 v3 → v4）

启动时自动完成：

1. 瓦片若绑定的是桌面本身（v2 默认）或桌面上隐藏的收纳文件夹（旧默认「手机文件夹」、或你用设置绑定的隐藏目录）→ 改绑到新的 `D:\手机文件夹`；
2. **旧文件夹里的文件会合并搬进新收纳目录**（同名自动 `(1)`，跨盘自动复制+删除），然后删掉空掉的旧目录；
3. 旧的隐藏目录「手机文件夹 / 文件夹」即使已不在配置里，只要还留在桌面且是隐藏目录，也会被搬空并删除；
4. 用户显式绑定的**普通可见文件夹**（非隐藏）不会被迁移，保留原样。

配置版本号升到 **v4**；迁移只执行一次。

## 5. 怎么查看收纳的文件

- 右键瓦片 →「打开绑定文件夹」，路径就是 `D:\手机文件夹`（普通文件夹，不再隐藏）
- 设置页里也会显示当前绑定的路径
- 想换成别的位置：设置 → 瓦片行「更改」

## 6. 说明 / 限制

- 收纳仍是**移动**语义：文件从桌面移进 `D:\手机文件夹`，桌面对应图标消失
- 如果某块磁盘/目录不可写，会自动回退到 `%APPDATA%\phone-folder\手机文件夹`
- 升级后如果桌面仍有你手动创建的其他隐藏文件夹，那不属于本应用管理范围，不会被动
