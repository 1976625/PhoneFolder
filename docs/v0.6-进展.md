# v0.6.0 行为修正记录（2026-10-27）

> 反馈：「部分与期望有些不符，是放在桌面上，默认空的，从桌面拖动我想放到瓦片里面的」
> 关联计划：[开发计划.md](开发计划.md)；上一阶段：[P5-进展.md](P5-进展.md)

## 1. 问题定位

原实现（v0.5.0）把**桌面本身**当成默认绑定文件夹：

- 瓦片一打开就显示桌面全部 35 项 → 不像「收纳盒」，更像桌面的另一个视图；
- 从桌面拖图标到瓦片上时，目标文件夹 == 桌面，源文件已在目标文件夹内 → 被判定 `skipped`，**看起来像拖入无效**；
- 因此用户期望的「默认空瓦片、从桌面拖东西进去收纳」完全没实现。

## 2. 修正内容（v0.6.0）

1. **默认绑定改为隐藏收纳文件夹**：首次启动自动创建 `<桌面>\手机文件夹`（用 `attrib +h` 设为隐藏，Explorer 默认不显示），瓦片绑定它 → **默认是空的**。
2. **配置迁移 v2 → v3**：已有配置若绑定的是桌面，自动改绑到新的空收纳文件夹；瓦片位置/大小/外观参数保留，**桌面上的文件不会被动**。用户之后拖进瓦片即可收纳。
3. **空态引导**：面板显示「这个瓦片还是空的 / 把桌面上的文件 / 文件夹拖到瓦片上或这里」；瓦片空态改为虚线边框，提示可以拖入。
4. **拖入 = 收进盒子**：从桌面把文件/快捷方式/文件夹拖到瓦片或浮层上 → 移进收纳文件夹，桌面图标消失、瓦片里出现；同名自动 ` (n)`；从浮层拖回桌面 = 移出。
5. E2E 更新为真实场景：**桌面临时文件 → 瓦片绑定的收纳文件夹**，验证移动、重名、重复拖入 skipped、浮层自动刷新。

> 收纳文件夹位置：`<桌面>\手机文件夹`（本机 `D:\deskTop\手机文件夹`）。
> 查看方式：右键瓦片 →「打开绑定文件夹」；或在资源管理器开启「显示隐藏项目」。
> 想绑到别的真实文件夹：设置页 → 瓦片行「更改」。

- 拖入是**移动**语义（收纳文件夹在隐藏目录里，文件仍在本地，可随时打开/移出）
- 首次启动的「教学提示」只有空态文案；如果觉得不够明显，可加一次性引导气泡
- 其余限制同 P5：拖出单文件、多显示器未适配、未签名

## 6. v0.6.1 微调（2026-10-27 二次反馈）

反馈：空瓦片里的「文件夹图标」不需要。

- 空瓦片改为**纯虚线框**（保留 2×2 容器圆角与虚线圈），不再显示 📂 图标；文件夹名标签保留。
- 有人拖入文件后恢复正常 2×2 缩略图/图标；错误态仍显示 ⚠️。
- 版本 0.6.1，重新打包 portable + zip。
- 若之后也不想要浮层空态里的 📂 提示图标，可以同样去掉（当前保留，用于说明「这里可以放文件」）。

## 7. v0.6.2 微调（2026-10-27 三次反馈）

反馈：①展开面板空态里的文件夹图标也不要；②未打开的瓦片边缘不要虚线，换成与展开面板一致的边缘。

- 浮层空态：不再显示 📂 图标，只保留「这个瓦片还是空的 / 把桌面上的文件 / 文件夹拖到瓦片上或这里」两行文字（错误态仍保留 ⚠️）。
- 空瓦片边缘：由虚线改为**与展开面板一致的实线玻璃边缘**（1px `rgba(255,255,255,.28)` + 顶部内高光 + 投影），拖拽悬停时显示蓝色高光。
- 版本 0.6.2，重新打包 portable + zip。
