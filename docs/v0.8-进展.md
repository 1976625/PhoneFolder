# v0.8.0 交互细节修正（2026-10-27）

> 反馈三连：
> 1. 桌面 hover 的时候顶上有一点遮挡；
> 2. 瓦片名字希望打开时点名字可以进入编辑；
> 3. 拖进去的快捷方式出现了后缀，希望隐藏后缀。

## 1. hover 顶部被裁 + 瓦片尺寸不生效

**根因**（两个叠加问题）：

- `.thumbs` 固定 84px，而瓦片窗口高度是 `size + 20`；窗口顶部即卡片顶部，hover `scale(1.04)` 以中心为原点向上放大 → 超出窗口顶部被裁掉一点；
- 更关键的是：设置里的「瓦片大小」只改了窗口大小，**卡片一直固定 84px**，视觉上不生效。

**修复**：

- 卡片尺寸跟随 `tile.size`：CSS 变量 `--tile-size` 由瓦片渲染层按 payload 设置，窗口尺寸设置现在真正生效（64–128）；
- 卡片比窗口小 6px（`calc(var(--tile-size) - 6px)`），四周留出放大余量；
- `transform-origin: center top`（只向下放大，不向上溢出）；
- 拖入高亮从 `outline` 改为 `inset box-shadow` 内环（不向外扩）；
- 2×2 间距、圆角、图标/字号、占位图标尺寸全部按 `--tile-size` 等比缩放。

**验证**：hover 截图 `shots/crop-hover-state.png` / `shots/hover/01-tile.png`：卡片 122px（size=128）、四周留白完整，顶部不再缺一块。

## 2. 点标题重命名瓦片

- 配置里新增可选字段 `tiles[].name`（v4 向后兼容，旧配置没有这个字段就显示文件夹名）；
- 浮层里**点击大标题** → 变成输入框（同字号、下划线高亮），`Enter`/失焦保存，`Esc` 取消；
- 新 IPC `tile:rename`：校验来源（瓦片/浮层）、清洗名称（去换行、压缩空格、最长 24 字；空名=恢复文件夹名）、写回配置；
- 保存后通过 `pushTileState` 同步刷新**浮层标题 + 桌面瓦片标签**，不需要重扫文件夹；
- 设置页保存 / 删除其他瓦片时都会保留 `name` 字段，不会把自定义名冲掉。

**验证**：`node scripts/e2e-rename.js` PASS：标题改为「我的收纳盒」→ 配置 `tiles[0].name` 同步 → 瓦片标签同步；清空后恢复为文件夹名「手机文件夹」。

## 3. 面板隐藏 .lnk 后缀

- 浮层条目显示名去掉 `.lnk` 后缀（只影响显示，文件本身不改名、路径操作不受影响）；
- 其它类型（文档、图片、压缩包等）保持原样。

**验证**：E2E 里面板条目显示 `_pf_suffix_test`、`UU加速器`，不再带 `.lnk`。
