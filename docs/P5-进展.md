## 4. 打包说明

```powershell
# 首次：安装 electron-builder（走 npmmirror 源）
pnpm install
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
pnpm dist          # 同时出 zip + portable（electron-builder.yml 配置）
```

- 配置：[electron-builder.yml](../electron-builder.yml)，`output: release`，`asar: true`（`assets/icon.ico` unpack）。
- 未配置证书，跳过签名；首次运行便携版可能有 SmartScreen 提示（点「更多信息 → 仍要运行」）。
- 便携版运行会解压到临时目录，配置与开发版共用 `%APPDATA%\phone-folder\config.json`；开机自启会指向 portable exe 本身（已处理）。

## 5. 打包踩坑

1. **打包后的 exe 启动即退**：排查发现不是打包问题——测试命令继承了 DSH 终端的 `ELECTRON_RUN_AS_NODE=1`，Electron 以 Node 模式运行并报 `bad option: --enable-logging`。清掉环境变量后正常。
2. **shot 模式图标变成渐变占位**：P4 重构后 `runShot` 直接 `overlay.open()`，没有设置 `overlayTileId`，图标 IPC 的文件夹校验失败。已在截图流程里补 `overlayTileId = tile.id`。
3. **便携版自启路径**：`app.getPath('exe')` 在 portable 模式下是临时解压目录，改用 `process.env.PORTABLE_EXECUTABLE_FILE`。
4. **打包后 userData 会变**：electron-builder 的 productName 会影响默认 appData 目录，显式 `app.setPath('userData', %APPDATA%\phone-folder)` 固定，开发/打包共用配置。
5. **asar 内不可写**：截图目录在打包后回退到系统临时目录。
